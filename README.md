# Vite + React + Redux Counter App

A simple and clean counter application built using **React**, **Vite**, and **Redux Toolkit**. The app showcases global state management using Redux and dynamic UI updates based on the counter value.

## Features

- 🔁 Counter with **Increment**, **Decrement**, and **Reset**
- 🎨 Dynamic color changes based on counter value:
  - 🔵 `0` – Default Blue
  - 🟢 `> 0` – Green
  - 🔴 `< 0` – Red
- ⚙️ Global state managed via Redux Toolkit
- ⚡️ Fast dev experience with Vite
- 💅 Styled using CSS Modules

## Installation & Setup

1. **Clone the repo**

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   
2. **Install dependencies**
  `npm install`
3. **Start the dev server**
  `npm run dev`
4. **Open in browser**
5. **Navigate to** `http://localhost:5173`

## Usage
Just click the +, -, or Reset buttons and watch the counter update in real-time, with dynamic color feedback.
